## The word

**Rosie** — the robot maid from the cartoons of grandma's era. It is the name she would give the machine in the corner, and the word she would text to her grandchild about it: warm, a little baffled, and unmistakably about a robot. One word, no sentence, no explanation, no punctuation tricks.

## Run it
